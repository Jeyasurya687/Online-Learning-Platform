# EduMaster - Beginner-Friendly Website

## Files
- `index.html` - website structure
- `style.css` - design and responsive layout
- `script.js` - beginner-friendly JavaScript interactions

## Interactive features
1. Mobile navigation menu
2. Course search
3. Course preview popup
4. Animated statistics
5. Newsletter form validation
6. Smooth scrolling
7. Responsive layout for mobile, tablet and desktop

## How to run
Open `index.html` in Chrome or VS Code Live Server.

## Beginner tip
Start by changing the text in `index.html`, then colors in `style.css`, and finally the button behavior in `script.js`.
